#HOW TO MAKE MOBS OBEY YOU
1. Make sure they do not target you while taming
2. Each mob type has a certain item, which can be used to tame them
3. Equip corresponding full armor set

#MOB ARMOR RECIPE
Combine Diamond Armor With Corresponding Material (in any order)
Example: 5 Creeper Material + Diamond Helmet = Creeper Helmet
There is also Herobrine armor, which can be created ... // TODO

!Exception
Piglins, Brute Piglins, Zoglins are tamed with golden armor set

#MATERIAL
Each type of material can be obtained from corresponding hostile entity with 5% chance (piglins, brute piglins, zoglins do not drop)
